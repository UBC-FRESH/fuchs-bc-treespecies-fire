# Forest Policy and Economics submission package

- `main-review.pdf` — anonymized manuscript for double-anonymized review (no author names, no supplement).
- `title-page.pdf` — title, authors, affiliations, corresponding author, contributions, funding, competing interests.
- `supplement.pdf` — online supplement, uploaded separately.
- `cover-letter.md` — draft cover letter addressed to *Forest Policy and Economics*.
- `highlights.txt` — five highlights, each within the 85-character limit.
- `main.pdf` — author version with affiliations and the supplement appended, for coauthors only.

The manuscript uses author-date citations and double spacing with line numbers. The journal accepts a
consistent initial-submission format; the Elsevier `elsarticle` template can be applied at revision or
acceptance.
