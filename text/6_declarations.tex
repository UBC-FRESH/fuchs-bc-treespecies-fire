\section*{Software and data availability}

The compiled TSA~24 dataset is derived from the public TSA~24 instance maintained by the UBC
FRESH laboratory~\citep{femic_tsa24_2026}, which is built from the provincial Vegetation Resources
Inventory, the Forest and Range Evaluation Program disturbance mapping, and Site Productivity
estimates, under the Open Government Licence (British Columbia). The instance carries the source licences.

The estate model is WS4~\citep{ubc_fresh_ws4_2026}, released under the Apache License 2.0; the
fire run uses the public estate-fire API. Harvest costing uses the FHOPS forest harvest and
operations planning library~\citep{fhops_2026}. The fire calibration, the historical perimeter set, the calibrated suppression
configurations, and the regional calibration JSON are documented in the calibration study
\citep{ubc_fresh_fire_calibration_2026}. They are archived with that study on acceptance; the raw
perimeter data are not redistributed here.

The state-based convergence schedules, the scripts that build the candidate and simulator caches,
the derived species-period table, the rotation summaries, the stocking-standard surface, the fuel
projection checks, the observed and calibrated-retention fire surfaces, the aspen-price and haul
sensitivities, and the valuation and rotation code are archived in a public repository with a DOI on
acceptance. The sensitivity values
are reproducible from the valuation code and the recorded constants.
