\section*{Software and data availability}

The compiled TSA~24 dataset is derived from the public TSA~24 instance maintained by the UBC
FRESH laboratory~\citep{femic_tsa24_2026}, which is built from the provincial Vegetation Resources
Inventory, the Forest and Range Evaluation Program disturbance mapping, and Site Productivity
estimates, under the Open Government Licence (British Columbia). The instance carries the source licences.

The estate model is WS4~\citep{ubc_fresh_ws4_2026}, released under the Apache License 2.0; the
fire run uses the public estate-fire API. Harvest costing uses the Forest Harvest and Operations
Planning System (FHOPS)~\citep{fhops_2026}. The fire calibration, the historical perimeter set, the calibrated suppression
configurations, and the regional calibration JSON are documented in the calibration study
\citep{ubc_fresh_fire_calibration_2026}. They are archived with that study; the raw perimeter data
are not redistributed here.

All results are reproducible from the analysis repository at
\url{https://github.com/UBC-FRESH/fresh-fuchs-ws4} (commit \texttt{c9975f9}):
\begin{itemize}
\item state-based convergence: \path{experiments/plantation/enterprise/state/*/result.json};
\item production and value: \path{experiments/plantation/enterprise/prod-converged.json};
\item fire surfaces: \path{experiments/plantation/enterprise/surface-converged-observed-summary.json}
and \path{surface-converged-calibrated-summary.json};
\item fuel projection: \path{experiments/plantation/t0-fuel-validation.json};
\item rotation: \path{experiments/plantation/enterprise/rotation-converged.json};
\item sensitivities: \path{experiments/plantation/enterprise/sensitivity-converged.json}.
\end{itemize}
The manuscript source is at \url{https://github.com/UBC-FRESH/fuchs-bc-treespecies-fire}. The
sensitivity values are reproducible from the valuation code and the recorded constants.
