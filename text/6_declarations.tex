\section*{Software and data availability}

The compiled TSA~24 dataset is derived from the public FEMIC TSA24 instance maintained by the UBC
FRESH laboratory \citep{femic_tsa24_2026}, which is built from the provincial Vegetation Resources
Inventory, the Forest and Range Evaluation Program disturbance mapping, and Site Productivity
estimates, under the Open Government Licence -- British Columbia. The instance and the frozen
benchmark artifact used here carry the source licences and the rebuild recipe.

The estate model is WS4 \citep{ubc_fresh_ws4_2026}, released under the Apache License 2.0; the fire run uses the public estate-fire API at commit \texttt{9918fb17}, with the durable handoff summaries at \texttt{474dca6e}. Harvest
costing uses the FHOPS machine-rate library \citep{fhops_2026}. The fire calibration, the
historical perimeter set, the calibrated suppression configurations, and the regional calibration
JSON are part of a companion calibration study. They are archived with that study on acceptance
and are not redistributed here; the manuscript does not depend on redistributing the raw perimeter
data.

The derived species-period table, the rotation summaries, the composition summaries, the fire
scenario record, the benchmark target, and the valuation and rotation code are held in the project
repository and will be archived with a DOI on acceptance. The block-level baseline schedule, the
composition run directories, and the model-schedule sensitivity runs remain on the work host; the
sensitivity values are reproducible from the valuation code and the recorded constants.
